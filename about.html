Buat sesuatu yang spesial untuk seseorang.

Tentang Platform

𝓤𝓷𝓽𝓾𝓴 𝓚𝓪𝓶𝓾 adalah platform untuk membuat project digital personal yang cantik dan mudah dibagikan. Pilih template, edit teks, warna, dan foto sesuai keinginan, lalu dapatkan link permanen untuk dibagikan kepada orang tersayang.

Cocok untuk surat cinta, ucapan ulang tahun, nembak, undangan, dan berbagai project personal lainnya.

Cara Menggunakan

  1. Daftar atau masuk ke akunmu
  2. Pilih template (gratis atau berbayar)
  3. Edit sesuai keinginan di editor
  4. Simpan dan dapatkan link unik
  5. Bagikan link kepada orang spesial

Sistem Saldo

Template berbayar dibayar menggunakan saldo internal. Top up melalui QRIS, lalu admin akan menyetujui pembayaran. Minimal top up Rp2.000 dan maksimal Rp1.000.000.

Keamanan & Privasi

Projectmu hanya bisa diedit oleh akun pemilik. Link publik hanya menampilkan isi project tanpa data akun. Project berbayar tidak memiliki branding website.
